# Per-function extra L2 regions (SA_L2_EXTRA syntax, docs/re/l2-oracle.md): HOOK@ADDR:LEN[:R|W|RW]
#
# For memory a function reads or writes that catalog/rwsets.csv cannot name: heap objects behind
# global pointers or behind `this`. ADDR/LEN are expressions evaluated at each case: numbers, registers
# at entry (ecx = this for thiscall), argN (stack arguments), [EXPR] = the dword at EXPR, + and -.
# A declared region is snapshotted, restored between the original and the Rust run, compared after
# both, and counts as declared for the undeclared-write check. tools/e2e/port-l2.sh passes the lines
# whose HOOK is in its hook list.
#
# Lines: the ARCH-1 pilots (CORE-L2) and PORT-CORE (CORE-L2b, below). Pool constructors need none: their
# header is `this` (declared by the hook signature) and the arrays they write are allocated inside the call.
#
# CPool<T> (layouts.csv CPool<int32>, 0x14 bytes): +0 objects, +4 byte map, +8 size, +0xC first free.
# Pools: ped [0xB74490], vehicle [0xB74494], object [0xB7449C].
