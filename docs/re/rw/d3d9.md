# D3D9 driver, instancing and pipelines

All addresses are 1.0 US. Names marked † are descriptive (RW static functions, see README §1); the rest are
public RW names from the thunks or from API slots.

## 1. Device

* `RwDevice` at .data 0x8e2498 (0x38 bytes), returned by `_rwDeviceGetHandle` 0x7f9c20:
  gamma 1.0, `fpSystem` = `D3D9System` 0x7f5f70, zBufferNear 0.0, zBufferFar 1.0,
  `fpRenderStateSet` = `_rwD3D9RWSetRenderState` 0x7fe420, `fpRenderStateGet` = `_rwD3D9RWGetRenderState`
  0x7fd810, Im2D line/triangle/primitive/indexed = 0x7fb650 / 0x7fb8e0 / 0x7fbb00 / 0x7fbd30. The Im3D
  slots (+0x28..+0x34) are 0 in the file and are filled by the immediate module at start-up.
* `D3D9System` 0x7f5f70 switch (request numbers from `rwplcore.h` `RwDeviceSystemRequest`):

| req | name | body |
|---|---|---|

| 8 | FOCUS | |

## 3. Rasters and textures

* Raster extension: `objects.md` (0x24 bytes at raster + [0xb4e9e0]).
* Create: `_rwD3D9RasterCreate` 0x4cce60 → `_rwD3D9RasterCreateFormatSelect`† 0x4cc5c0 (type/format →
  D3DFORMAT with `_rwD3D9CheckValid*` 0x4cbd80/0x4cbde0/0x4cbe20/0x4cbe80/0x4cbee0/0x4cbf20,
  autogen-mip checks 0x4cbfd0/0x4cc020), `_rwD3D9RasterCreatePalettized`† 0x4cb7c0,
  `_rwD3D9RasterCreateTexture`† 0x4cb9c0 (CreateTexture vtbl+0x5c / CreateCubeTexture +0x64, retry on
  D3DERR_OUTOFVIDEOMEMORY), `_rwD3D9RasterCreateZBuffer`† 0x4ccd70 (D16/D24S8/D24X8/D32),
  `_rwD3D9ClampRasterSize`† 0x7fed70. Camera/Z/dynamic rasters go on the video-memory raster list
  (`_rxD3D9VideoMemoryRasterListAdd/Remove/Release/Restore/Create/Destroy` 0x4cb530/0x4cb560/0x4cb640/
  0x4cc970/0x4cc150/0x4cb5e0).
* Image ↔ raster: `_rwD3D9ImageGetRasterBody`† 0x7ff450 → `_rwD3D9ConvertRasterToImage`† 0x7ff8c0 with 19
  pixel→RGBA converters 0x7ffbe0–0x7ffee0; `_rwD3D9RasterSetImage` 0x8001e0 →
  `_rwD3D9GetRGBAToPixelConverter`† 0x800810 (15 converters 0x800930–0x800c20),
  `_rwD3D9RasterSetImageMipmaps`† 0x800c80, `_rwD3D9RasterSetImagePalettized`† 0x801390,
  `_rwD3D9ImageFindFormat`† 0x7ffff0.
* DDS: `RwD3D9DDSTextureRead` / `RwD3D9RasterStreamReadDDS` (thunks), software DXT decompression
  `_rwD3D9DecompressDXT1/3/5`† 0x81e720/0x81ea70/0x81edc0 (+0x81f0c0). Native TXD: slots 25–27 above.
* Textures: `RwTextureRead` 0x7f3ac0 (find callback, else read callback; texture module data at
  engine + [0xc97b4c]); defaults `_rwTextureDefaultFindCallBack`† 0x7f53d0 and
  `_rwTextureDefaultReadCallBack`† 0x7f40f0 (image read + mask + mipmaps 0x7f4690/0x7f44c0/0x7f4ae0/0x7f5140).
  The game replaces them (CTxdStore, `RwTextureSetFindCallBack` 0x7f34d0 / `SetReadCallBack` 0x7f3500).

## 4. Render-state cache

`_rwD3D9RWSetRenderState` 0x7fe420 switches over `RwRenderState` and calls cached setters that compare with
the cached value and queue the D3DRS id into the deferred list 0xc98b40 (count 0xc9a5ec):
`_rwD3D9SetTextureInternal`† 0x7fdcd0 (TEXTURERASTER), texture filter 0x7fdb80, src/dest blend 0x7fdc30 /
0x7fdc80 (table 0x88490c), z test/write 0x7fea70 / 0x7feb70, shade mode 0x7fec70, border colour 0x7fecc0,
cull 0x7fed00, stencil 0x7fe1a0–0x7fe3d0. `_rwD3D9RWGetRenderState` 0x7fd810 reads the caches. Public
`RwD3D9SetRenderState`, `RwD3D9SetTextureStageState`, `RwD3D9SetSamplerState`, `_rwD3D9RenderStateFlushCache`
etc. are thunks. Cache init `_rwD3D9RenderStateOpen`† 0x7fcac0, reset after device reset
`_rwD3D9RenderStateReset` 0x7fd100, invalidate `_rwD3D9RenderStateCacheInvalidate`† 0x7f6b00.
Anisotropy level from RpAnisot: `_rwD3D9SetMaxAnisotropy`† 0x7fde60 (0xc9a5e8).

## 5. Instancing (resEntry) path

Data: `RwResEntry` (0x18) followed by `RxD3D9ResEntryHeader` (0x40) and `numMeshes` × `RxD3D9InstanceData`
(0x24), allocated from the resource arena (`RwResourcesAllocateResEntry` 0x807ed0) by
`_rpD3D9InstanceMeshes`† 0x756960 with destroy notify `_rxD3D9DefaultDestroyInstanceCallback`† 0x4c9990
(frees index buffer via 0x730d30, `RwD3D9DeleteVertexDeclaration`, vertex streams, removes dynamic
geometry `_rpD3D9RemoveDynamicGeometry` 0x74e9e0). The resEntry is cached in `atomic->repEntry` (+0x14) or
`geometry->repEntry` (+0x58) / `sector->repEntry` (+0x34); `geometry->lockedSinceLastInst` (+0xc) ≠ 0
forces reinstancing. Device restore (`_rpD3D9WorldRestoreCallback`† 0x74ea80) marks every geometry on
the dynamic list 0xc92520 with 0xfff.

Flow of `RpAtomicRender` → `atomic->renderCallBack` (+0x48, default `AtomicDefaultRenderCallBack` 0x7491c0)
→ `RxPipelineExecute(atomic->pipeline ?: default atomic pipeline at pipe module +0x3c)` → node body:

* **Atomic all-in-one** `_rwD3D9AtomicAllInOneNode`† 0x7575f0 (node definition returned by
  `RxNodeDefinitionGetD3D9AtomicAllInOne` 0x7582e0; body/init pointers at .data 0x8d633c/0x8d6348).
  Node init `_rwD3D9AtomicAllInOnePipelineInit`† 0x757890 stores the private callbacks
  `{instance = _rxD3D9DefaultInstanceCallback† 0x7578c0, reinstance = _rxD3D9DefaultReinstanceCallback†
  0x758270, lighting = _rxD3D9AtomicDefaultLightingCallback† 0x757400, render = _rxD3D9DefaultRenderCallback†
  0x756df0}`; accessors `RxD3D9AllInOneSet/Get{Instance,Reinstance,Lighting,Render}CallBack`
  0x757380–0x7573f0 (thunks). The body checks numMeshes/geometry, (re)instances when the serial number or
  lock flags changed, then calls lighting and render. Vertex data conversion uses the
  `_rpD3D9VertexDeclarationInst*` family 0x752320–0x755aa0 (thunks) and `RpD3D9GeometryGetUsageFlags`.
* **World sector all-in-one** `_rwD3D9WorldSectorAllInOneNode`† 0x75e3f0
  (`RxNodeDefinitionGetD3D9WorldSectorAllInOne` 0x75e9f0; .data 0x8d63bc/0x8d63c8), init 0x75e540 with
  `{instance 0x75e5e0, reinstance NULL, lighting 0x75e570, render 0x756df0}`.
* **Vertex-shader path** (used by skin and the game's pipes when shaders are available):
  `_rpD3D9GetVertexShader` 0x75eed0 → `_rpD3D9VertexShaderGenerate`† 0x75f0b0 (assembles shader text, calls
  `D3DXAssembleShader` and `RwD3D9CreateVertexShader` 0x7fac60), cache purge 0x75ee60, constants helpers
  0x761720–0x761b70, `_rwD3D9VS*` matrix helpers 0x7646e0.. (they call D3DX math, §8).
* Default pipelines are created in `_rpWorldPipeOpen`† 0x75e310 (WORLD module open):
  `_rpCreateD3D9WorldSectorAllInOnePipe`† 0x74ead0 and `_rpCreateD3D9AtomicAllInOnePipe`† 0x74eb80
  (`RxPipelineCreate`, `pipeline->pluginId` = 2, `RxPipelineLock`, `RxLockedPipeAddFragment` 0x806be0,
  `RxLockedPipeUnlock`, set default).
